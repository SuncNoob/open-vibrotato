# vibrotato 游戏指南

*open-vibrotato 项目 · 版本 2.3.1 「星阵交错」*

## 这是一款什么游戏

vibrotato 是一款不依赖任何服务器、账号或网络连接的**单文件离线动作生存游戏**。
把 `vibrotato.html` 保存到本地双击打开，就是完整游戏——没有安装包，没有下载进度条，没有第三方框架。

一局游戏从**只有一把 I 级武器**开始。你要在 20 个波次里且战且抢，靠随机掉落的武器、核心和词条，
在信用点和战场资源之间反复取舍，拼出一套只属于这一局的连招体系；波次结束或角色阵亡即为一局的终点。
没有两局构筑是完全相同的——这正是这类构筑生存游戏（build-survival / bullet heaven）最核心的乐趣。

## 核心玩法循环

1. **走位躲弹幕，武器自动索敌开火** —— 你只需要操心"站在哪"，攻击本身是自动的。
2. **波次结束进商店**：花信用点购买武器、道具、核心，或把用不上的装备拆解换取材料。
3. **合成与定向**：两把同名、同改装、同等级的武器可以合成升级，最高合成到 IV 级（终局形态）；
   看好某个方向也可以对武器做"定向"，提高它继续开出同款强化的概率。
4. **核心组装**：核心不是被动加成，而是带条件的机制改写器——比如"生命低于 40% 时攻速 +60%"，
   或"每三次挥砍额外打出两道交叉回响"。每局最多装两颗，第三颗需要主动替换，不会偷偷顶掉已选的核心。
5. **下一波，难度继续爬升**：敌人数量、生命、速度、精英概率都随波次和你选择的危险等级同步提高。

打完 20 波即为"街区已解放"；倒下则以死亡记录复盘最后 8 秒的伤害来源，帮助你判断下一局怎么调整构筑。

## 12 名角色，12 种打法起点

每个角色不是换皮，而是一套明确的"给什么、限制什么"的构筑倾向：

| 角色 | 英文代号 | 定位 | 核心机制 |
|---|---|---|---|
| SP-01 街头 | THE ORIGINAL | 自由构筑 | 无附加规则，任何武器都能成为答案 |
| 独狼 | LONE WOLF | 少即是多 | 全武器伤害 +60%，但硬限 3 槽 |
| 机枪手 | BULLET CHEF | 高频射击 | 攻速 +40%、射程 +20%，但不能装近战 |
| 装甲兵 | IRON POTATO | 护甲反击 | 生命 +60、护甲 +15，代价是移速与拾取范围下降 |
| 赌徒 | LOADED DICE | 幸运变奏 | 幸运 +50%，但每波会随机替换一把武器 |
| 工程师 | HIVE MAKER | 机械军团 | 工程标签武器伤害 +65%，其余武器大幅减伤 |
| 吸血鬼 | RED COVENANT | 贴身续航 | 生命偷取 +8%，但正常回血被锁为 0 |
| 拾荒者 | SCRAP SAINT | 拾取经济 | 素材获取 +30%、拾取范围 +100%，起始信用点为 0 |
| 刀锋舞者 | BLADE DANCER | 多刀交错 | 只能装刀刃，冲刺后太刀立即就绪 |
| 磁轨猎手 | DEADEYE | 贯穿暴击 | 只能装精准武器，伤害与暴击同步提升 |
| 元素使 | TRIUNE | 冰火电融合 | 只能装元素武器，允许冰/火/电三态共存触发核心 |
| 爆破专家 | DEMOLITION | 聚怪爆破 | 只能装爆裂武器，爆炸半径与伤害同步提升 |

角色之间的差异会直接决定你要走哪条构筑路线，建议先用 SP-01 街头熟悉系统，再挑战限制型角色。

## 武器系统

- **20 个武器家族**，覆盖脉冲步枪、机炮、霰弹、狙击、火焰、冰锥、雷电、腐蚀、引力、奇点、
  近战刀刃、环绕刀刃、感应地雷、无人机等远程 / 近战 / 部署 / 元素四大类型。
- **5 档稀有度**，波次越靠后，商店权重越向高稀有度倾斜（第 1 波高稀有权重几乎为零，第 15 波显著提升）。
- **合成成长**：两把条件相同的武器可合成升level，最高 IV 级为终局形态，之后无法再合成。
- **近战独立挂点**（本版重点）：同一角色装备多把同款近战武器时，每一把都拥有独立的悬浮挂点方位，
  按刀数均分 360°，不会因为混装枪械或角色转身而挤成一把刀糊在一起；2 / 4 / 6 / 8 把近战都有清晰可辨的挥砍轨迹。

## 核心（Core）系统

核心是这一版最具策略深度的部分，每颗都有明确的**触发条件、机制效果与代价**，例如：

- **猩红反应堆**（残血狂战）：生命不高于 40% 时攻速 +60%、近战伤害 +35%，代价是最大生命 −10、治疗效果 −40%。
- **折镜刀匣**（交错回响）：每把高频太刀第三次挥击追加两道 70% 伤害的交叉回响，代价是全局伤害 −10%。
- **蜂群协议**（工程成军）：同时装备 3 把以上工程武器时召唤伴机，代价是非工程武器伤害 −30%。
- **三相熔炉**（元素融合）：同一敌人身上冰火电三态共存时引爆融合爆炸，代价是伤害与护甲双降。

每局最多同时装备两颗核心，鼓励围绕"条件 → 效果 → 代价"做取舍，而不是无脑堆叠数值。

## 危险等级与难度曲线

解锁后的危险等级（Danger 0–5）会同步提高敌人生命、数量、移速与精英概率；
通关一次即解锁下一档，允许你按自己的节奏爬难度，而不是被迫从最高难度开始。

## 操作方式

| 操作 | 功能 |
|---|---|
| WASD / 方向键 | 移动，武器自动选敌攻击 |
| Space / Shift | 冲刺，短暂无敌 |
| Q | 释放 EMP，清除敌弹并击退近敌 |
| C / Tab | 打开构筑与属性面板 |
| E | 战利品背包，决定安装或拆解 |
| F / 右上角按钮 | 全屏切换 |
| Esc | 暂停 / 关闭面板 |
| M | 静音 |
| 手机：左侧摇杆 + 右侧技能按钮 | 双指同时移动与释放技能 |

## 适合谁玩

如果你喜欢《吸血鬼幸存者》一类的"自动战斗 + 构筑抽卡"节奏，又想要更强的武器手感（尤其是近战多刀的视觉表现）
和更有条件感的核心系统，vibrotato 提供的是一局 15–30 分钟、无需联网、无需安装、随时可以从头再来的体验。

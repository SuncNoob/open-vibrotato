# CHANGELOG — NEON SPUD 2.3.0 核心觉醒

## 交付范围与来源

本次交付是实际可玩的 20 波单文件游戏，不是前次的独立 UI/数值验证器。基于本次实际可访问的原始上传工程重新集成；无法访问的历史 2.2 文件未被冒充为本次合并输入。`src/engine.js` 和 `build.py` 原样保留。

以下参数是本版真实实现值。相对于前次设计讨论的变化属于“设计方案 → 本次实现”，并非声称对不可读取的历史可执行文件做了数值差分。

## 01 / 把难触发的核心做成值得追求的目标

| 核心 / 参数 | 讨论方案或基准 | 2.3 实现 | 预期改变的行为 |
|---|---|---|---|
| 猩红反应堆 | 低血 +35% 攻速、近战 +20% | ≤40% 血量时 +60% 攻速、近战标签伤害 +35% | 真正围绕低血窗口进攻，而不只是偶尔得到一个小加号 |
| 折镜刀匣 | 第三刀一次 65% 回响 | 每把太刀第三刀触发两次 70% 交错回响 | 多刀、保持接敌和连续攻击有可见回报；不是把暴击数字放大 |
| 量子副膛 | 第三次直射追加两发各 55% | 各 60%，按单次基础伤害，不复制整片霰弹 | 鼓励高频触发，但仍要接受射程 −15% 与全局触发间隔 |
| 三相熔炉 | 三态组合机制 | 240% 基准伤害、半径 4.8、消耗三态 | 值得为冰火电覆盖投入槽位，优先找能吃满爆发的密集敌群 |
| 相位残像 | 冲刺残迹机制 | 一次穿过 3 个不同敌人，路径上三段各 110% 斩击 | 冲刺从纯逃生变为带风险的穿阵进攻，而不是按冷却空放 |
| 寄生圣约 | 寄生治疗机制 | 近身精英/首领击杀回 20% 最大生命、+35% 攻速 10 秒，常驻吸血 5% | 有理由贴近高价值目标，而不是在安全距离用小怪无限回血 |
| 蜂群协议 | 部署伴随机机制 | 工程装备 ≥3，增加两台 65% 工程均值的伴随机 | 第三件工程武器成为明确构筑节点，不能单核白嫖完整召唤流 |
| 奇点弹芯 | 聚怪机制 | 主爆炸命中 ≥3 后吸附，再追加 140% 坍缩 | 优先创造聚怪窗口，而不是所有单发爆炸都免费升级 |

不是统一提高全部常驻属性。核心仍有最大生命、伤害、护甲、射程、移动、治疗、价格或冷却代价。最多装两颗、同名唯一；第三颗必须选择替换，不返还旧核心价格。

### 防失控边界

- 折镜每次回响最多命中 3 目标，全局间隔 0.28 秒；量子全局间隔 0.24 秒。
- 融合全局 1 秒、同目标 3 秒间隔；奇点 1.1 秒间隔，且真实要求三目标。
- 蜂群伴随机最多 2 台；素材充能最多 24；装甲反冲护盾最多 24。
- 金库每 60 信用点 +4% 伤害，最多 +24%；新报价 +8%，不回改锁价，不额外造钱。
- 核心衍生攻击不再触发其他核心、不吸血。普通持续伤害的近身精英击杀仍可触发寄生奖励，避免把常规元素/流血玩法误判为核心复制链。
- 吸血按实际扣除的敌人生命计算，受每秒最大生命 12% 上限与治疗减效约束；过量伤害不额外回生命。
- 修复致命主攻击与嵌套爆炸同时处理时可能产生负伤害统计的重入边界；濒死目标不会再次成为有效扣血对象。

## 02 / 核心不是说明卡：接入真实战斗

12 个核心分别接入实际挥刀、开火、命中、元素状态、爆炸命中数、部署物、拾取、真实护甲减伤、无伤计时、冲刺轨迹和精英击杀事件。

条件进度在战斗 HUD 中显示，满足时有独立提示/光效；战斗结束显示触发次数、核心衍生伤害。常驻属性增益不伪装成可精确归因的“总 DPS”。

## 03 / UI 从理解到付款形成闭环

- 核心详情固定顺序：奖励、门槛、当前进度、代价、机制边界、付款后的属性与余额。
- 槽满先选替换对象，再确认扣款；不默认删除旧核心。
- 刷新前发现未锁定核心时提醒，可一键锁住后返回。
- 购买降低余额时，金库伤害预览按付款后余额重新计算；最大生命变化不白送治疗。
- 稀有度、名称、类型、套装标签和伤害属性分开呈现。传说使用橙色边框/图标/武器效果，并保留文字标识。
- 手机详情奖励文字 16px、代价 15px；主要操作区固定，购买按钮大触点；弹窗键盘焦点循环，避免 Tab 进入背后界面。
- 竖屏单列商品、横屏双列，手指可真实滚动商店与详情。全锁定时不收费刷新。

## 04 / 单武器开局与可成长的武库

- 十二角色都只从指定的一把 I 级武器开始。
- 普通 6 槽，上限 8；独狼固定 3，精准猎手固定 4。
- 两把同款同改装同等级合成。满槽可购买同级材料直接合成；其他重复购入仍占独立槽位。
- 可确认拆除；最后一把保护；回收依据实际投入，合成累计两把投入，不随波次涨价套利。
- 同款报价定向分支 68%，两轮未匹配保底；保底不覆盖锁定格。
- II/III/IV 自然成品在第 4/9/15 波开放；定向可以匹配已经合成的较高等级。
- 保留 20×6=120 条目，其中六款终式到手 IV、不可升级、同名唯一，没有增加武器数量。

## 05 / 经济数值与行为目标

| 参数 | 2.3 数值 | 理由与预期行为 |
|---|---|---|
| 波次物价 | `1 + .052×(w−1) + .0035×(w−1)²`，最多 3.8 | 后期变贵但不指数膨胀，仍可存钱买关键件 |
| 普通成品等级溢价 | `2.1^(等级−1)` | 凑材料更省钱，成品卖的是时间和槽位便利 |
| 固定 IV 终式系数 | 4.8 | 少走合成路线有溢价，但不是永远买不起 |
| 刷新 | `9+2w+10n+5n²` | 少量刷新可承担，连续追指定核心会明显挤压当前战力预算 |
| 波末奖金 | `20+3w` | 活过一波有基本消费能力，不强迫每个角色都贴脸拾完素材 |
| 散落回收 | 信用点 65%、经验全额 | 走位安全与经济效率有取舍，经验不因漏拾而永久崩盘 |
| 利息 | 余额 2%、单波最多 8 | 鼓励适度存款，不让理财压倒战斗收入 |
| 武器拆除 | 实付累计投入的 35% | 容许转流派，但不能无成本频繁换装或靠涨价套利 |
| 免费掉落拆解 | 原基价 22% | 战利品有保底价值，不随晚期物价制造无穷资金 |
| 修复 | 按实际补血量收费，单次最多补 30% 上限 | 缺少量生命时也能合理购买，不必等接近死亡 |

核心第 5 波起进入自然报价，第 6/12/18 波有报价保底；保证遇见机会，不免费给核心，也不保证指定流派答案。锁定造成的保底延后保留玩家优先级。

## 06 / 角色、属性与实体模型

实现 12 位角色、16 项可正可负的原始属性。生命等实际可用值有安全下限，护甲实际减伤与闪避上限均为 60%。角色武器硬约束同时作用于商店和装备入口。

机体使用独立几何组合而非单纯换色：履带重装、单臂披风、双肩炮、骰子躯体、双机械臂机舱、中空肋架、回收背包、交错背刀、独眼瞄具、悬浮裂壳、桶式弹药机身等。灰模对比与彩色对比由生产渲染器绘制。

## 07 / 近战、波次与死亡可读性

- 每把太刀的挂点、目标、攻击计时、左右挥向、命中记录独立；第三刀 1.3 倍重斩。基础太刀 24 伤害、0.82 秒间隔，单刀默认最多 4 目标。
- 真实前摇/扫刀/收刀；伤害跟随刀锋扇区，不是整圈范围持续扣血。刃环保留部署物定位。
- 普通近战命中约 34ms 顿帧、暴击 50ms；触屏为 12/20ms，有触发节流。顿帧期间仍处理玩家移动。
- 20 波规定时长 815 秒；敌人 HP 使用超线性曲线 `base×(1+.28(w−1)+.045(w−1)^1.6)`。
- 普通追击、绕后、远程距离控制、自爆、冲刺蓄力不同；精英护盾/分裂/狂暴/召唤；首领三种预警攻击、两阶段及阶段二场地危险。
- 玩家头顶常驻数字/分段条、脚下血环；HUD 16px，约 0.4 秒残影；50%/25% 生命档位以颜色以外的文字、形状和动效表达。
- 死亡页保留明确致命来源、实际伤害和最近八秒记录，自伤与负回复也有命名。

## 08 / 手机与负载

独立 pointer capture 区分移动和技能手指。按下就释放技能，抬起技能手指不清掉移动；反向输入无平滑滞后。旋转、触摸取消、失焦与暂停都清空旧方向。素材与道具自动收包，但负项安装留给波后。

触屏绘制上限预算 30 Hz，输入/模拟仍每动画帧运行；菜单 24 Hz，暂停/商店背景 10 Hz，减少在 UI 后面全速渲染的浪费。仍需真机测试确认帧率与续航。

# NEON SPUD 2.3.0 — 核心觉醒 / COREBREAK

完整可玩、单文件离线的 3D 生存构筑游戏。不是 UI 实验室，也不是只有战斗演示的武器沙盒。

## 打开游戏

构建产物为项目根目录的 `NeonSpud.html`。将文件保存到设备，再用允许执行本地 JavaScript、支持 WebGL2 的浏览器打开。游戏没有 CDN、外部图片、外部字体、服务器或网络资源依赖。

聊天附件预览、某些手机文件管理器的预览窗口可能不会执行游戏。应使用实际浏览器，而不是静态预览。首次点击“开始行动”才能初始化浏览器音频。

本次自动化使用断网 Chromium 加载原样构建产物，实际 WebGL2 绘制正常且请求记录为零。受当前受控浏览器环境限制，没有验证 `file://` 双击打开流程，也没有进行 iOS Safari 或实体手机测试。零网络依赖不等于所有设备的文件管理器都能直接运行 HTML。

## 版本来源

本版以当前对话中实际上传的 `NeonSpud_Source.zip` 原始工程为基础重新集成。历史消息中的 2.1、2.2、2.3 Lab 下载地址无法在本次环境中取得，因此本版不是对那些不可访问文件进行的逐字节合并。

已在这一实际工程中实现单武器开局、角色/属性/升级、槽位合成、混合商店与经济、独立多刀、核心系统、手机触控以及差异化模型。原上传文件的 `src/engine.js` 与 `build.py` 保持字节一致，哈希记录见 `tests/original-hashes.json`。

## 一局的规则

- 12 位角色，所有角色从自己指定的 **一把 I 级武器** 开始。
- 普通角色 6 个武器槽；道具最多扩至 8 槽。独狼固定 3 槽，磁轨猎手固定 4 槽。
- 同型号、同改装、同等级的两把武器合成后升一级，最高 IV。重复购入会占用独立槽位；商店的“购入并合成”支持满槽付费升级。
- 可确认拆除武器并返还记录投入的 35%；最后一把不可拆除。合成会减少套装件数，不是无代价提升。
- 120 个武器条目由原有 20 家族 × 6 个有代价的改装组成，没有再扩张武器数量。六款“终式”到手 IV、同名唯一、不可合成。
- 64 件组件、24 项人物进化选项、9 类 2/4/6 件套装、12 件独特核心。每次人物升级三选一，至少一项带负项，不赠送武器。
- 全局共 20 波，Danger 0–5；完成当前危险等级解锁下一级。精英、潮汐、弹幕、断电、首领波有不同规则。
- 20 波规定战斗计时合计 **815 秒（13 分 35 秒）**。选择、商店、命中顿帧及未击败首领会延长总时长；15–20 分钟是体验目标，不是已证明的真人平均时长。
- 仅危险等级与最好成绩保存在本地；本版没有中途保存整局进度。

## 核心：高门槛换高回报

核心同名唯一，最多装两颗；安装第三颗必须明确选择替换对象。购买前展示条件、效果、代价、付款后属性和余额。战斗中展示条件进度与触发提示，结束后显示触发次数和可归因的衍生伤害。

| 核心 | 达成条件 | 奖励 | 主要代价 / 边界 |
|---|---|---|---|
| 猩红反应堆 | 当前生命 ≤40% | +60% 攻速、近战标签伤害 +35% | 最大生命 −10；战斗治疗仅剩 60% |
| 折镜刀匣 | 每把实际太刀每第三次挥击 | 两次交错回响，各为触发挥击的 70% | 全伤害 −10%；每次回响最多 3 目标；全局间隔 0.28 秒 |
| 量子副膛 | 每把非工程直射武器每第三次攻击 | 两枚追踪副弹，各为单次基础伤害的 60% | 射程 −15%；全局间隔 0.24 秒 |
| 蜂群协议 | 同时装备至少 3 件工程武器 | 两台伴随机，每台每 0.65 秒发射一发 65% 工程均值伤害 | 非工程直射伤害 −35%；伴随机硬上限 2 |
| 三相熔炉 | 同一敌人同时带火、冰、电状态 | 消耗三态，触发 240% 的 4.8 米融合爆炸 | 全伤害 −10%、护甲 −4；全局 1 秒、同目标 3 秒间隔 |
| 奇点弹芯 | 一次主爆炸命中至少 3 个敌人 | 吸附后延迟坍缩，额外 140% 伤害 | 主爆炸伤害 −20%；间隔 1.1 秒 |
| 金库引擎 | 每保留 60 信用点 | 伤害 +4%，360 存款时最多 +24% | 新生成报价 +8%；不改变锁价，不额外产钱 |
| 静电拾荒 | 在场上实际拾取 12 单位素材，再主攻击命中 | 125% 伤害的连锁，最多 5 目标 | 全伤害 −8%；最多存 24 充能；波末回收不充能 |
| 逆相装甲 | 用护甲实际减免累计 30 点敌人伤害 | 反冲伤害 35+1.4×护甲（最高 180），获得 12 护盾 | 闪避 −8%、移速 −5%；护盾最多 24；自伤不充能 |
| 时间断层 | 连续 8 秒未损失生命 | 3 秒内敌人、敌弹、敌方预警推进速度降至 45% | 移速 −10%；玩家及波次计时不减速 |
| 相位残像 | 一次冲刺穿过 3 个不同敌人 | 路径留下三段斩击，每段为最强武器基础单次的 110% | 冲刺冷却 +0.7 秒；每段对同目标只命中一次 |
| 寄生圣约 | 在 4 米以内击杀精英或首领 | 回 20% 最大生命、10 秒 +35% 攻速；常驻吸血 5% | 最大生命 −25、生命承伤 +15%；核心衍生击杀不能触发奖励 |

“伤害百分比”是对应事件的基础伤害，不是保证命中后的总 DPS。融合爆炸对触发伤害有最低基准 18，再乘 2.4。散射副弹按单发，不按整次霰弹总和计价。吸血按实际扣除的敌人生命计算，不把过量伤害当治疗资源。

核心衍生攻击不能继续触发核心、不能再次吸血；普通持续伤害的近身精英击杀仍可触发寄生圣约。图鉴、提示、数值配置及生产测试对应同一机制。

## 商店与经济

四格混卖武器、组件与稀有核心。每格可锁定，跨波保留该报价。第 6 / 12 / 18 波提供一次核心报价机会；全格锁定时延后，不顶掉玩家保存的商品。这是遇见保底，不是免费赠送，也不是保证指定核心。

精准同款材料的定向分支为 68%，匹配型号、改装和等级；两轮未匹配保底仅替换可刷新武器格。自然高等级商品于第 4 / 9 / 15 波开放 II / III / IV 级；定向可跟随现有等级提前出现。

- 物价：`min(3.8, 1 + 0.052×(波次−1) + 0.0035×(波次−1)²)`。
- 普通成品：每提升一级，基础报价乘 2.1；终式采用固定基价系数 4.8，再计波次物价。
- 刷新：`9 + 2×波次 + 10×本波已刷新数 + 5×已刷新数²`。第一波为 11、26、51、86。
- 波末赏金：`20 + 3×波次`；存款利息 2%，每波最多 8；未拾取素材回收信用点为 65%，经验不打折。
- 武器拆除按实际已支付投入返还 35%，不按后续上涨的标价套利。免费战利品按原基价 22% 拆解。
- 修复按实际能补的生命收费，最多补 30% 上限，不会缺一点血也收整包钱。

本版不会通过赠送多把起始武器、无限槽位或自动安装负面道具来抹平经济决策。

## 战斗与机体

太刀拥有独立挂点、计时、目标、左右方向、三段节奏和命中记录。伤害跟随真实扇区扫过；六把刀不是同一张光圈重复扣血。第三刀有 1.3 倍重斩，折镜回响是另外两次延迟攻击。轨道刃环仍是明确标识的环绕部署武器。

12 种程序化机体使用不同几何组合：装甲兵履带重甲、工程师机械臂机舱、吸血鬼中空肋架、元素使裂壳悬浮晶体、爆破专家桶式机身与导弹等。`tests/screenshots/07-models.png` 与 `08-models-gray.png` 为生产渲染器截图，不是概念图。

## 操作与手机

电脑：WASD / 方向键移动，Space / Shift 冲刺，Q EMP，C / Tab 构筑，E 战利品，Esc 暂停，1/2/3 升级选择，M 静音，滚轮缩放。武器自动索敌。

手机：左侧摇杆模拟推幅，右侧技能按下即触发。移动与技能手指独立，反向不插值拖尾；取消触摸、旋转、失焦、开面板会清理旧输入。左侧战场空白区也可以作为浮动摇杆起点。商店与详情支持手指滚动，购买区固定在底部。

靠近素材和掉落道具会自动收取，道具进入待安装背包，战斗中不强制安装。波后再决定接受负面代价还是拆解。

头顶数字/分段血条、脚下生命环常驻；HUD 血条 16px、伤害残影约 0.4 秒；警戒/濒危用文字、形状、脉动与边缘提示共同表达。低生命触发心跳和音乐低通，死亡显示致命来源与最近八秒受伤记录。

触屏绘制预算为每秒最多 30 次，输入与模拟仍在每次动画帧处理；菜单 24、暂停/商店背景 10 次绘制预算。这是负载预算，不是所有手机都能达到的帧率承诺。

## 构建与开发测试

```sh
python build.py
node tests/sim_checks.js
xvfb-run -a python tests/verify.py
node tests/long_runs.js
xvfb-run -a python tests/render_models.py
```

`verify.py` 需要开发环境里的 Node、Chromium 和 Python Playwright；渲染对比另需 Pillow。这些不是玩家运行游戏的依赖。没有图形环境时可执行：

```sh
python tests/verify.py --simulation-only
```

主要文件：

```text
src/engine.js      原样保留的 WebGL2 渲染管线
src/weapons.js     武器/改装/角色/组件/核心定义和 SVG 图标
src/game.js        BALANCE、战斗、经济、核心事件、独立机体
src/ui.js          主菜单、升级、商店、对比、背包和触控
src/style.css     桌面、竖屏、横屏、字号和色觉友好提示
src/index.html    离线打包模板
build.py          原样保留的单文件打包器
weapon-catalog.json
item-catalog.json
tests/            可重复测试、原始 JSON 报告、实际渲染截图
```

系统性调参入口在 `game.js` 顶部 `BALANCE`；家族基础值、角色偏移和具体组件组合在 `weapons.js`。修改后运行模拟测试会同步导出两个目录 JSON，再运行构建与浏览器测试。

## 验证边界

详见 `VALIDATION.md`。机制、交易、真实 UI 与多指输入接受自动化验证；真人“爽感”、各流派平衡、首次通关率、真机发热/续航和跨浏览器性能没有被自动化代替。无敌长流程只用于验证 20 波状态链，明确不是正常难度通关证明。
